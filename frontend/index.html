Executive Dialogue & Return Drift

Predicting 5-Day Post-Earnings Abnormal Returns via Linguistic Drift

This system evaluates corporate earnings presentation scripts and unscripted analyst Q&A sessions. By contrasting real-time executive sentiment, evasiveness, and semantic entropy against a company's historical baseline, the active ML model projects whether 5-day cumulative abnormal returns (CAR) will beat or lag the market.

End-to-End ML Pipeline Architecture

How raw transcript text is transformed into actionable market direction estimates
Stage 01
Transcript Ingestion & Splitting
Raw audio transcripts are parsed into structured scripted Presentation and unscripted Analyst Q&A dialogue blocks.
Stage 02
Sentence NLP Tokenization
Transformer embeddings extract sentence-level sentiment polarity, semantic entropy, and QA topic evasiveness scores.
Stage 03
Historical Z-Scoring
Current call metrics are normalized against the company's trailing 8-quarter baseline to isolate true linguistic surprises.
Stage 04
XGBoost Direction Classifier
An expanding window tree model evaluates drift features to output the probability of a positive 5-day abnormal return.
